- The framebuffer, evdev, LVGL and APPLaunch integration follows this repository's `amiibo_sim/lcd.cpp` and packaging conventions (MIT); see `../amiibo_sim/LICENSE`.
- LVGL v9.5.0 is MIT licensed. The installed documentation includes LVGL's `LICENCE.txt`.
- MiMoKit by RiviaRammer was consulted for its ASR / chat / TTS architecture and PCM streaming examples (commit `52bec1a089540732abd76e43ab8d789184c9398d`). No MiMoKit implementation is copied into this project. https://github.com/RiviaRammer/MiMoKit
- Xiaomi MiMo API schemas and model defaults follow the official documentation retrieved on 2026-11-14. URLs are in README.md.
- Python requests, ALSA utilities, CA certificates and Droid fallback fonts are runtime Debian dependencies, not bundled here. Their upstream and Debian license terms apply.
